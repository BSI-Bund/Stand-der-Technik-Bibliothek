# Assessment Layer

Der Assessment Layer ist für maschinenlesbare OSCAL-Artefakte zur Planung,
Durchführung und Nachbereitung von Prüfungen vorgesehen. Dazu gehören
insbesondere:

- Assessment Plans,
- Assessment Results,
- Plans of Action and Milestones (POA&M).

Derzeit sind in diesem Bereich noch keine Artefakte veröffentlicht.
