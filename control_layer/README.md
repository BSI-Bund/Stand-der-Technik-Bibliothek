# Control Layer

Kataloge sind maschinenlesbare, standardisierte Sammlungen von
Sicherheitsanforderungen. Sie dienen als strukturierte Datenbasis, um
Kontrollvorgaben eindeutig und automatisierbar zu dokumentieren.

Der Control Layer enthält:

- OSCAL-Kataloge mit einzelnen Anforderungen,
- OSCAL-Profile zur Auswahl und Anpassung von Anforderungen,
- aus Profilen aufgelöste OSCAL-Kataloge,
- Mapping Collections zur Zuordnung verschiedener Kataloge.

Direkt nutzbare Artefakte liegen in den fachlich zugeordneten
Unterverzeichnissen. Zugehörige maschinenlesbare Quellkataloge und Profile
können dort unter `sources/` liegen.

Mit
[OSCAL-Katalogen](https://pages.nist.gov/OSCAL/learn/concepts/layer/control/catalog/)
wird der traditionelle, oft manuelle Prozess der Sicherheitsdokumentation
durch einen datenzentrierten Ansatz ersetzt. Dies ermöglicht eine
effizientere und konsistentere Verwaltung von Sicherheits- und
Compliance-Anforderungen.
